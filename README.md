# Pass Zone Heat Map & Pass Success Rate Analyzer

アメリカンフットボールのパスデータを可視化するWebベースの分析ツールです。  
Excelファイルをブラウザにドラッグ＆ドロップするだけで、**投球割合ヒートマップ（Pass Zone）**、**パス成功率フィールド図（Pass Success Rate）**、および **ゾーン別詳細集計表** を即座に自動生成します。

---

## 🏈 特長

* **1枚インポート対応**: 単一のExcelファイルをドロップするだけで即時に解析・可視化
* **ブラウザ完結**: サーバー不要（完全クライアントサイド動作）。データが外部に送信される心配はありません
* **高解像度画像保存**: 出力されたフィールド図と集計表をワンクリックでPNG画像としてエクスポート可能
* **GitHub Pages対応**: `index.html` 単体でGitHub Pages等へのホスティングが可能です

---

## 📊 入力Excelのフォーマット仕様

Excelの先頭行（ヘッダー）に以下の列が含まれている形式に対応しています：

| 列名 | 必須/任意 | 説明 |
|---|:---:|---|
| **`PASS ZONE`** | **必須** | 投球ゾーン番号（`1` 〜 `9`） |
| `OPP PASSER` | 任意 | パサー番号（自動で無視されます） |
| **`PASS RESULT`** | **必須** | `G`（成功） / `NG`、投げ捨て、QSC等（不成功） |
| `PLAY TYPE` | 任意 | プレイ種別（Pass等） |
| `GN/LS` | 任意 | 獲得・喪失ヤード |

### 判定ルール
* **対象データ**: Runプレイは除外し、パスプレイ（`PASS ZONE` が1〜9の行）のみを集計対象とします。
* **成功判定**: `PASS RESULT` 列が **`G`（大文字・小文字問わず）のみを成功（Complete）**、それ以外（`NG`、投げ捨て、QSC、サック、空欄等）はすべて **不成功（Incomplete）** として判定します。

## 🚀 使い方

### ローカルで使う場合
1. `index.html` をブラウザ（Google Chrome, Safari, Edgeなど）で開きます。
2. 対象のExcelファイル（または付属の `sample_data.xlsx`）を画面の中央にドラッグ＆ドロップします。
3. 投球割合ヒートマップ、パス成功率図、およびゾーン別集計表が自動表示されます。
4. 右上の「画像として保存」ボタンを押すと、分析結果をPNG画像としてダウンロードできます。

### GitHub Pages で公開する場合
1. 本リポジトリをGitHubにプッシュします。
2. リポジトリの **Settings** > **Pages** を開きます。
3. **Branch** を `main`（または `master`）、フォルダを `/ (root)` に設定して保存します。
4. 発行されたURLにアクセスすれば、どのPCやタブレットからでもツールを利用できます。
